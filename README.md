# SM3 国密哈希算法（C++ 工程化实现）

## 简介
本项目是 **SM3 密码杂凑算法** 的 C++ 工程化实现，符合国家密码管理局 **GM/T 0004-2012** 标准。

## 特性
- ✅ 完整实现 SM3 填充、消息扩展、64 轮压缩
- ✅ 通过官方标准测试向量（空串 / "abc" / "abcd"×16）
- ✅ CMake 构建系统
- ✅ 单元测试 + 性能基准测试
- ✅ 吞吐量约 190 MB/s（WSL + GCC -O2）

## 编译运行
```bash
mkdir build && cd build
cmake .. && make
./sm3_test
```

## 测试结果
